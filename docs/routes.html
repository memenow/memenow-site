Routes & content

Every public URL on memenow.xyz, the chapter it represents, and the file that owns the copy. The site is served in seven languages — /zh, /zh-TW, /en, /ja, /ko, /es, /fr — and reads as one continuous narrative; additions belong in this map.

[locale] is a SvelteKit param with a matcher (src/params/locale.ts) accepting exactly the codes in src/lib/i18n/locale-registry.ts (zh, zh-TW, en, ja, ko, es, fr); case variants such as /zh-tw/… 301 to the canonical spelling. Every page consumes the active dictionary (one file per locale under src/lib/i18n/dictionaries/, sent by +layout.server.ts) via useMessages(), and the root layout emits per-locale canonical, hreflang, and og:locale tags. hooks.server.ts owns the redirect policy: retired URLs (/products/quant, /disclaimer) 301 to their localized replacement; legacy unprefixed page URLs 302 to the negotiated locale (the memenow.locale cookie, else the first Accept-Language tag). The pure decision functions live in src/lib/i18n/locale-path.ts.

The family column controls which fog gradient activates on html[data-route-family] via src/lib/styles/scene.css. Legal pages get a near-flat veil so the eye stays on the type; threshold pages get the celestial fog. Classification logic lives in src/lib/utils/route-family.ts.

Legal pair — /privacy, /terms

Both carry <meta name="robots" content="noindex"> and open with an editorial .c-legal-summary overview card (three plain-language points plus an in-page section jump bar) above left-aligned chapters rendered against the legal fog. They are still listed in the sitemap because the URLs are stable and discoverable from the footer.

/privacy is intentionally short: no third-party analytics, no advertising; theme and motion preferences stay in browser-local storage, the locale preference lives in a first-party cookie used only to render the chosen language, and Cloudflare keeps standard request metadata.

/terms covers scope (memenow.xyz), the cultural-inquiry and AI-generated-content disclaimer, "as is" provision, the no-financial-offer clause, intellectual property (including the reader's rights over personal readings), and Delaware governing law.

Sitemap — /sitemap.xml

The sitemap is a +server.ts route with prerender = true so it ships as a static file inside the asset bundle. Its URL list lives in src/lib/data/sitemap.ts as a ReadonlyArray of [path, lastmod] pairs over logical (unprefixed) routes; the handler expands each route across every locale with mutual xhtml:link hreflang alternates plus an x-default pointing at the negotiating root. Hand-bump the lastmod when content meaningfully changes — search crawlers discount uniform "everything updated today" stamps. 

// src/lib/data/sitemap.ts
export const SITEMAP_ROUTES: ReadonlyArray<readonly [path: string, lastmod: string]> = [
    ['/', '2026-05-28'],
    ['/products', '2026-05-28'],
    // …
];

The handler in +server.ts emits a one-hour Cache-Control. Tests in server.test.ts verify the content type, the cache header, and that every URL appears exactly once paired with its frozen lastmod.

Error page — +error.svelte

src/routes/+error.svelte renders both 404 and 500 responses. It branches on page.status (404 vs. everything else) and deliberately renders a generic, pre-defined message instead of page.error.message, which can leak internals; it carries <meta name="robots" content="noindex"> and offers a Return home CTA pointing at the current locale's home. It reuses EditorialHero with no image so it sits in the same continuous scene as every other route, and it is localized — the error copy follows the negotiated locale even for URLs that match no route.

Adding a new route

  1. Create src/routes/[locale=locale]/<path>/+page.svelte. Compose with EditorialHero + Chapter; provide <svelte:head> with title, description, and (if it deserves social sharing) og:title / og:description / og:image.
  2. Add the page's copy to every dictionary in src/lib/i18n/dictionaries/ — the zh dictionary owns MessageSchema, so no other locale typechecks until it matches key-for-key; dictionaries.test.ts also rejects empty strings and markup drift.
  3. Decide the route family. If the URL belongs in the legal family, add it to LEGAL_PREFIXES in src/lib/utils/route-family.ts and add a test case.
  4. If you want it in the floating dock or footer, add it to src/lib/data/navigation.ts (hrefs take the locale prefix via the locale argument).
  5. Append the unprefixed path and a YYYY-MM-DD lastmod to src/lib/data/sitemap.ts — the handler expands it across locales. If the URL already existed unprefixed, add it to LEGACY_PAGE_PATHS in src/lib/i18n/locale-path.ts so the old link redirects.
  6. If the page should be hidden from indexing, add <meta name="robots" content="noindex"> in its <svelte:head>.
  7. Run pnpm lint && pnpm check && pnpm test before pushing.
Editorial language The site ships seven languages: Simplified Chinese (/zh), Traditional Chinese (/zh-TW), standard American English (/en), Japanese (/ja), Korean (/ko), Spanish (/es), and French (/fr). Product terms follow the yinyang-agent-ui terminology catalog. The committed English copy is the factual baseline; every other locale stays plain and faithful to it — no claims, features, or imagery that the English source doesn't make. Keep chapter titles short and write ledes at human-thoughtful cadence rather than marketing copy.
