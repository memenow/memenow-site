Components

The Svelte component catalog grouped by responsibility. Every component is a Svelte 5 rune-mode module — props are declared with $props(), never with export let.

Brand

Component Path Purpose
MemenowMark lib/components/brand/MemenowMark.svelte The brand mark and lockups, served as a <picture> with avif / webp / png at @1x and @2x.

MemenowMark accepts a variant (mark, lockup-vertical, lockup-horizontal, reverse), a size (sm | md | lg | xl mapped to a height in pixels), and an optional eager flag to opt out of lazy loading. The image base URL is derived from the variant — never hand-write <img src="/brand/…">; use this component.

Home — narrative scroll primitives

Component Path Notes
EditorialHero lib/components/home/EditorialHero.svelte Full-viewport hero with optional background image, scrim, eyebrow row, large title, lede, optional cta snippet, and scroll cue. Title uses reveal with splitWords: true; lede, CTA, and cue use reveal-fade.
Chapter lib/components/home/Chapter.svelte One narrative section. Supports align (center | left | split), banner (extends image to inner edge), and headless (drops the number / label row). Optional cta snippet renders below the body.

Both EditorialHero and Chapter take an optional image of type SceneImage (from $lib/types), which carries the AVIF / WebP / PNG sources plus intrinsic w / h so the layout reserves box geometry and Cumulative Layout Shift stays at zero. On the inner routes the hero is rendered without an image, floating over the world layer.

Chapter alignment recipes

  • align="center" (default) — title centered, body centered, single column. Best for openers and short statements.
  • align="left" — title and body left-aligned. Used for quieter chapters that don't carry a hero image.
  • align="split" — sticky title in the left column, body / image / CTA flow in the right.
  • banner — image extends to the chapter's inner edge with a 21:9 aspect ratio.
  • headless — drops the 01 — Label row and keeps just the title. Used when adjacent chapters already establish the cadence (e.g. home The studio).

The Chapter component has dedicated browser tests in Chapter.svelte.test.ts covering each alignment and the options above.

UI primitives

Component Path Notes
ArtifactCta lib/components/ui/ArtifactCta.svelte The studio's signature call-to-action. Warm moon-gold diamond mark, magnetic hover. variant selects outline (default, ink hairline on paper) or filled (ink fill inverting on hover). Drops the magnet under reduced motion.
ScrollCue lib/components/ui/ScrollCue.svelte Silent, clickable downward hairline chevron mounted inside EditorialHero when scrollTarget is passed. Zero visible text; screen-reader aria-label only. Cooperates with Lenis smooth scroll and stops animating under reduced motion.
TrustedHtml lib/components/ui/TrustedHtml.svelte Renders static inline markup (strong, code, a) from repo-authored legal dictionaries only; never accepts user or request input.
LocaleSwitch lib/components/ui/LocaleSwitch.svelte Language menu in the floating dock: a native <details> disclosure whose trigger shows the active locale's short label (简, EN, 日…) and opens upward to seven plain links, one per locale, each pointing at the current page in that language (switchLocalePath) with hreflang, lang, and aria-current. Works without JavaScript; with it, Escape (focus returns to the trigger), an outside click, or picking a language closes the menu. Links carry data-sveltekit-noscroll; the server persists the choice to the memenow.locale cookie. The footer repeats the seven links as a no-JS path.
ThemeSwitch lib/components/ui/ThemeSwitch.svelte Sun / moon icon button. Mirrors data-theme on mount, toggles on click, persists to localStorage.memenow.theme. Tolerant of storage failures (Safari private mode, quota exceeded). Browser tests cover every branch.
MotionSwitch lib/components/ui/MotionSwitch.svelte Waveform / dash icon button in the floating dock. Mirrors data-motion on mount, toggles between full and reduced on click, persists to localStorage['memenow.motion'], and starts or stops Lenis. Can both honor and override the OS prefers-reduced-motion setting. Tolerant of storage failures. Browser tests cover every branch.

Class composition

cn(...inputs) in src/lib/utils/cn.ts is a thin clsx wrapper. There is no tailwind-merge: components in this codebase are .c-* primitives that do not stack conflicting Tailwind utilities. If you ever need to compose conflicting utilities, swap in tailwind-merge at that site rather than working around the limitation. 

import { cn } from '$lib/utils/cn';

<a class={cn('c-artifact-cta', variant === 'filled' && 'c-artifact-cta--filled', size !== 'md' && `c-artifact-cta--${size}`, className)}>
    {@render children()}
</a>

Snippets & children

Components that wrap content take a children: Snippet prop and call {@render children()}. Components with optional secondary slots (CTA, header) take a named cta or similar Snippet. There is no slot fallback API in runes mode; use a default Snippet argument instead.

Adding a new component Pick a directory by responsibility (brand, home, layout, ui). Add a matching .c-* primitive in src/lib/styles/components.css if it needs styling beyond what the existing primitives offer. If it has interactive behavior, add a *.svelte.test.ts alongside it so the browser project picks it up.
